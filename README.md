# 酒馆项目

本仓库用于承载酒馆项目的需求、设计、研发、测试与交付物。

## 目录结构
- docs/：架构与决策文档
- prd/：产品需求文档（PRD）
- design/：交互与视觉设计
- research/：用户/竞品/调研
- src/：源代码
- tests/：测试用例与报告
- scripts/：自动化脚本
- config/：配置与环境说明
- assets/：素材与资源
- data/：样例/测试数据
- infra/：基础设施与运维
- ci/：持续集成配置
- deploy/：部署相关
- logs/：运行日志（不入库）
- temp/：临时文件（不入库）

## 使用说明
- PRD 及相关规范见 prd/ 与 docs/
- 研发从 src/ 开始，脚本放在 scripts/
